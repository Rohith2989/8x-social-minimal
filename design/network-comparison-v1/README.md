# A different way to grow — comparison proposal

Approved for implementation and now built on the root homepage after Dot Reach. Original concept generated with built-in image_gen and refined to make the compact selector clearly control the entire content region. Saved image: `01-section.png`. Exact generation and refinement prompts: `prompts.json`. Runtime UI uses HTML/CSS and SVG, not this raster.

Source content: https://www.8x.social/en/for-brands, inspected 2026-09-17. The original includes a comparison of creator networks, influencer marketing and Meta advertising after the recent-work gallery. The proposed design keeps that business topic, rephrasing the selected 8x state into content, distribution and management. No invented performance metrics, customer results or comparative cost claims.

One shared stone surface, ordinary document scrolling, no rules or panel backgrounds. The upper edge shows a fragment of the preceding content to communicate adjacency. Main headline, compact mode tabs and three open content columns. All three benefit columns shown describe 8x; they are NOT headings beneath separate competitor columns. Generated cropped media fragment is context only, not a new production asset. Use existing original video at runtime.

Implemented interaction: keyboard-accessible compact tabs swap the entire three-column explanation within fixed dimensions. Active orange dot marks the selected label. Small SVG dot glyphs reconfigure over 280ms with bounded stagger and copy crossfades over 160ms, without moving the page or stealing scroll. Reduced motion uses immediate state changes. No new pinned interval. Competitor copy describes sponsored posts/existing audiences/campaign partnerships and ad creative/paid placement/campaign controls. It does not imply other providers cannot offer management or that influencers use fake accounts. Mobile uses a stacked reading layout with small orange bullets rather than the desktop glyph row.

The original orange map comes later. Do not place a stone map here, recolor the atlas or use this proposal to remove the service choices/dashboard/brand-proof content still needed.
