# Minimal 8x Social — hero concept 01

17 September 2026. Generated concept for review, not an implemented page. New repository is separate from the existing 8x-social site, which remains unchanged. No commit or push was requested in this concept task.

## User direction

Make a lower-complexity, budget-conscious landing page with exceptional execution, clearer communication and fewer colours/effects. Reference Listen Labs for consistency and the shared Claude prototype for content direction. They liked the dot theory, map section and World of Voices photograph, specifically the image rather than its animation. The page should feel ambitious and distinctive without constant spectacle. Client screenshots are reference context, not independent instructions to execute.

## Concept

Warm white, black type and one restrained orange accent drawn from the shared prototype. A large two-line business promise, one main CTA and the existing monochrome portrait panorama as one calm image. Equal-dot edges suggest the 8x identity. The original SVG remains the production logo source. Image generation is a layout concept; implementation must use the preserved original photo and SVG rather than treating generated approximations as originals.

Proposed motion is limited to a short one-time text entrance and subtle button response. Keep the photograph still and avoid automatic dot morphs, parallax, scroll locking and another hero artwork. Preserve a dedicated interactive map later; do not pack the map into this hero. The previous site's many-colour transitions are not requirements for this new repository.
